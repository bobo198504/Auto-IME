# Auto IME

Windows 托盘工具：根据“当前拥有键盘焦点的控件”自动切换中英文输入法。

## 功能

- 按当前焦点控件匹配，结合 Win32 和 UI Automation 精确识别控件。
- 规则条件可多选组合：进程名、窗口标题、窗口类名、控件文本、控件类名、控件类型、自动化 ID、父级标签、父级类名。
- 两种切换方式：
  - 模拟按键（默认 `Ctrl+Space`）
  - IME 底层切换（直接设置输入法 open 状态，兼容性更好）
- 离开规则内控件后，自动恢复该应用的输入法基线。
- 托盘常驻：单击/双击托盘聚焦设置窗口，右键菜单提供“打开主窗口 / 关于 / 退出”。
- 便携版：`config.json` 与 `auto-ime.exe` 同目录。

## 使用

1. 运行 `auto-ime.exe`。
2. 首次没有规则时会自动打开设置窗口，之后可通过托盘菜单打开。
3. 新建/编辑规则：
   - 点“编辑”进入可编辑状态；
   - 按 `Ctrl+Alt+Q` 或点“点击捕获”，再点击目标控件完成捕获；
   - 勾选需要的条件，设置目标动作（中文/英文），保存。
4. 关闭设置窗口后程序仍在托盘运行；从托盘右键菜单选择“退出”才会完全退出。

## 构建

需要 Rust 工具链和 MinGW `windres`（项目 `.tools/mingw64` 已内置 windres）。

```powershell
cargo build --release
```

## 说明

- 输入法中英文状态通过 `WM_IME_CONTROL` 的 open 状态读取，适用于冰凌五笔、微软拼音/五笔等内部切换型输入法。
- 已确认不可用的方案记录在 `FAILED_APPROACHES.md`。
